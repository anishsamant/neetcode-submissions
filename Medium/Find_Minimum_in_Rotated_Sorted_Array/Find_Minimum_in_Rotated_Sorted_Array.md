<details class="hint-accordion">  
    <summary>Hint 1</summary>
    <p style="font-size: 17px;">
    A brute force solution would be to do a linear search on the array to find the minimum element. This would be an <code class="hljs language-stylus" style="font-size: 14.5px;">O(n)</code> solution. Can you think of a better way? Maybe an efficient searching algorithm is helpful.
    </p>
</details>

<br>
<details class="hint-accordion">  
    <summary>Hint 2</summary>
    <p style="font-size: 17px;">
    Given that the array is rotated after sorting, elements from the right end are moved to the left end one by one. This creates two parts of a sorted array, separated by a deflection point caused by the rotation. For example, consider the array <code class="hljs language-csharp" style="font-size: 14.5px;"><span class="token punctuation" style="font-size: 14.5px;">[</span><span class="token number" style="font-size: 14.5px;">3</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">4</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">1</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">2</span><span class="token punctuation" style="font-size: 14.5px;">]</span></code>. Here, the array is rotated twice, resulting in two sorted segments: <code class="hljs language-csharp" style="font-size: 14.5px;"><span class="token punctuation" style="font-size: 14.5px;">[</span><span class="token number" style="font-size: 14.5px;">3</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">4</span><span class="token punctuation" style="font-size: 14.5px;">]</span></code> and <code class="hljs language-csharp" style="font-size: 14.5px;"><span class="token punctuation" style="font-size: 14.5px;">[</span><span class="token number" style="font-size: 14.5px;">1</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">2</span><span class="token punctuation" style="font-size: 14.5px;">]</span></code>. And the minimum element will be the first element of the right segment. Can you do a binary search to find this cut?
    </p>
</details>

<br>
<details class="hint-accordion">  
    <summary>Hint 3</summary>
    <p style="font-size: 17px;">
    We perform a binary search on the array with pointers <code class="hljs language-ebnf" style="font-size: 14.5px;">l</code> and <code class="hljs language-ebnf" style="font-size: 14.5px;">r</code>, which belong to two different sorted segments. For example, in <code class="hljs language-csharp" style="font-size: 14.5px;"><span class="token punctuation" style="font-size: 14.5px;">[</span><span class="token number" style="font-size: 14.5px;">3</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">4</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">5</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">6</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">1</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">2</span><span class="token punctuation" style="font-size: 14.5px;">,</span> <span class="token number" style="font-size: 14.5px;">3</span><span class="token punctuation" style="font-size: 14.5px;">]</span></code>, <code class="hljs language-abnf" style="font-size: 14.5px;">l = 0</code>, <code class="hljs language-abnf" style="font-size: 14.5px;">r = 6</code>, and <code class="hljs language-abnf" style="font-size: 14.5px;">mid = 3</code>. At least two of <code class="hljs language-ebnf" style="font-size: 14.5px;">l</code>, <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code>, and <code class="hljs language-ebnf" style="font-size: 14.5px;">r</code> will always be in the same sorted segment. Can you find conditions to eliminate one half and continue the binary search? Perhaps analyzing all possible conditions for <code class="hljs language-ebnf" style="font-size: 14.5px;">l</code>, <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code>, and <code class="hljs language-ebnf" style="font-size: 14.5px;">r</code> would help. 
    </p>
</details>

<details class="hint-accordion">  
    <summary>Hint 4</summary>
    <p style="font-size: 17px;">
    There will be two conditions where <code class="hljs language-ebnf" style="font-size: 14.5px;">l</code> and <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code> will be in left sorted segment or <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code> and <code class="hljs language-ebnf" style="font-size: 14.5px;">r</code> will be in right sorted segement.
    If <code class="hljs language-ebnf" style="font-size: 14.5px;">l</code> and <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code> in sorted segement, then <code class="hljs language-css" style="font-size: 14.5px;">nums[l] &lt; nums[mid]</code> and the minimum element will be in the right part. If <code class="hljs language-arcade" style="font-size: 14.5px;">mid</code> and <code class="hljs language-ebnf" style="font-size: 14.5px;">r</code> in sorted segment, then <code class="hljs language-css" style="font-size: 14.5px;">nums[mid] &lt; nums[r]</code> and the minimum element will be in the left part. After the binary search we end up finding the minimum element.
    </p>
